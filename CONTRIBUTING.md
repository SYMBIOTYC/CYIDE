# Contributing

Thank you for helping improve CYIDE.

## Branches

- `main` is protected. Use feature branches and open PRs.
- PRs should be small and focused.

## Commits

- Use clear, imperative subject lines.
- Group unrelated changes into separate commits/PRs.

## Tests

- Run `npm test` before pushing.
- Add tests for adapter behavior changes.

## Documentation

- Update `README.md`, `docs/`, and `AGENTS.md` when behavior changes.
- Keep the single source of truth aligned.

## Security

See `SECURITY.md` for vulnerability reporting.
